# Traveller Sheet

A browser character sheet for a homebrew tabletop game, in two looks:

- `character-sheet.html` – the standard sheet
- `character-sheet-crt.html` – the same sheet as a green phosphor terminal

Characters save in your own browser. Download a `.json` file from the Settings
(or Library & saves) tab to back one up or move it to another device.

The game library (feats, careers, origins, spells, gear…) is exported from an
Obsidian vault and loaded on the Library tab.
